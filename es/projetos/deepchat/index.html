DeepChat

DeepSeek responde y ChatGPT comprueba la respuesta.

alyssom-fernandes.github.io/DeepChatPantallas de la demo pública, con datos ficticios
Abrir la demoCódigo

Por qué existe

Desde el comienzo de las IA, sus respuestas no siempre son confiables para tareas, trabajo o estudios. Para comprobarlas, yo llevaba la respuesta de una IA a otra, con la misma pregunta, hasta que las dos debatían y llegaban a un consenso. Hacer de mensajero cansaba; DeepChat se convirtió en un «grupo de WhatsApp» con las dos IA que más usaba.

Problema, sistema y comprobación

Problema

Comprobar una respuesta obligaba a copiar y pegar entre dos IA.

Sistema

Chat en el que DeepSeek responde y ChatGPT revisa la respuesta con un veredicto, puntos fuertes, qué mejorar y, cuando hay un error, una versión revisada. Sin servidor: todo se ejecuta en el navegador.

Comprobación

65 pruebas

node --test en GitHub Actions. Verificadas el 9/11/2026.

Por dentro

  1. alyssom-fernandes.github.io/DeepChat

    Veredicto destacado

    Cada respuesta recibe un veredicto: correcta, parcialmente correcta o incorrecta.

  2. alyssom-fernandes.github.io/DeepChat

    Versión revisada

    En la demo, la función que valida el CPF (número de contribuyente brasileño) sale parcialmente correcta porque acepta 111.111.111-11, y la revisión trae la versión corregida.

  3. alyssom-fernandes.github.io/DeepChat

    Sin servidor

    Las preguntas van directamente del navegador a las API y las claves, si se guardan, quedan cifradas. La demo no necesita clave.

  4. También en el teléfono

    La misma conversación y la misma revisión, con un diseño propio para teléfono.
