ArtMaker

Encartes de ofertas prontos para o Status do WhatsApp.

alyssom-fernandes.github.io/ArtMakerTelas da demo pública, com dados fictícios
Abrir a demoCódigo

Por que existe

Uma pessoa me pediu ajuda para fazer as artes de promoção dos produtos do mercado dela. Se eu fizesse as artes, ela sempre dependeria de mim. Por isso fiz uma ferramenta que simplifica a criação: ela configura tudo como quiser e recebe a arte pronta no final.

Problema, sistema e prova

Problema

Cada arte de promoção dependeria de alguém que soubesse montar.

Sistema

Gerador de encartes de ofertas 1080×1920 no formato do Status do WhatsApp, num único arquivo HTML com Canvas. Salva tudo no próprio aparelho.

Prova

33 testes

node --test no GitHub Actions. Conferidos em 9/11/2026.
